Fonts for the greeting card makers, loaded with the FontFace API in js/diwali-card.js and drawn onto the card
canvas. Both are under the SIL Open Font License 1.1, which allows embedding; the licence texts are next to this file.

- Yatra One (The Yatra Project Authors): yatra-one-deva.woff2, yatra-one-latin.woff2
- Noto Sans Devanagari 500 and 700 (The Noto Project Authors): noto-sans-devanagari-*.woff2

woff2 subsets (devanagari, latin) from Fontsource.
